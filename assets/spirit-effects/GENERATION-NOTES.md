# Painted apparition effects

Generated with the built-in image generation tool on 2026-10-15. Original RGBA outputs are retained unchanged. Runtime Canvas drawImage crops atlas cells; no raster postprocessing was used.

`vapor-atlas.png`: six isolated, airy, ivory ectoplasm wisps in a 3×2 equal-cell transparent atlas. Prompt requested feathered silver-blue strands, painterly translucent edges, left-to-right trailing shapes, generous padding, no characters/text/neon/rings/bubbles. The simulation emits near the lower body, inherits bounded velocity, applies drag and a mild downward settle, then fades. This is an optional painted effect, not a fluid simulation.

`floating-eyes.png`: two pairs of isolated eyes derived from the original cute/scary Wisp assemblies using built-in image editing. Prompt requested cute bright-blue forward eyes at left and sinister narrow blue eyes at right; true alpha, eyelid edges but no skin plate/body/mouth/brows/background/text. Scary upper lids remain sculptural. Runtime uses explicitly measured crop rectangles; originals remain intact.

These assets introduce no third-party runtime dependency. Existing assembled reference artwork remains untouched.
