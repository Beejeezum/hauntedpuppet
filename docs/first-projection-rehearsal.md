# First house-projection rehearsal

This first pass tests the prepared friendly film, placement, sound and output control. It does **not** approve live animated conversation, scary acting, the cute/evil morph or the finished attraction.

Use the actual laptop, projector, speakers, intended show lighting and normal guest approach. No API key is needed for this filmed preview:

https://hauntedpuppet.netlify.app/assets/wisp-film-preview/index.html

## Run the first pass

1. On the laptop, leave sample sound off and choose **Living idle**. Open **Open silent rehearsal output**, move that window to the projector display, then choose **Full screen** there. Keep the operator page on the laptop.
2. Make the entire rectangular output fit the projection area. Watch several full cycles: crest, hands, lower core and every fog thread need clearance. Check the actual mapped surface as well as the browser image.
3. Stand where guests approach and where they stop at the door. Check whether eyes, expression, hand gestures and the connected body read clearly. Look for an obvious illuminated rectangle, washed-out facial detail, uneven focus, jitter or clipped smoke. Note the conditions and distance rather than compensating by cropping the fog.
4. Back at the laptop, choose **Enable sample voice**, then **Greeting → living idle**. Listen from the guest positions. Check intelligibility, character appeal, the end of the spoken line and the visual return to idle. The output window must remain silent; sound belongs to the laptop/speaker path.
5. Press **Blackout / stop** on the laptop. The projected character should clear immediately and audio should stop. Restart idle, then try **Escape** in the output window. Keep the stage black until you explicitly restore it from the operator page.

The same-window Escape recovery fix is under review. Until it is published, an escaped output can remain latched black: close that output, reopen it from the laptop and place/fullscreen it again. Do not interpret this known limitation as a projector failure.
