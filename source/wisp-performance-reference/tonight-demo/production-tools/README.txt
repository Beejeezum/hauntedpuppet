Run these source staging tools from the repository root with Python, numpy and OpenCV. Set HAUNT_FFMPEG to your ffmpeg executable or install ffmpeg on PATH; the Mac authoring fallback uses the existing local work bundle. Each tool refuses to overwrite an existing output. No tool calls AI providers or opens audio/capture.

The approved scare/apology section has human approval for sequence and mix direction. Departure and writing are studies awaiting final-context acceptance. Bats source v1 is rejected for clipping; its corrected keyframe requires human approval before the full video edit. Source task metadata and all-frame RGB reports are evidence with explicit limits; none alone approves a film or physical projection. These files are NOT automatically published as runtime assets.
