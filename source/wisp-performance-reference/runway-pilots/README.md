## Reproducible local rehearsal

Serve the repository root with a static loopback server and open `source/wisp-performance-reference/runway-pilots/wisp-timed-speech-review.html`. Production server deliberately does not serve source/. Use `Play timed greeting`; audio defaults muted. This waits for mouth artwork and decoded body footage, performs the gesture and generated line, then returns to idle. Manual cues, Blackout and disposal stop the generated audio. No microphone, provider call or credentials are involved.

The mouth is still an experimental tracked patch with three coarse shapes, not an approved face rig. Automatic alignment does not establish phoneme accuracy. Video body acting is prerecorded, and this is not an implementation of native live conversation. Keep the source demo excluded from the public build.

### Decoded framing review

`python3 scripts/review-wisp-film.py path/to/input.mp4 work/review-name` creates a nine-frame contact sheet and all-frame JSON diagnostics without modifying the film. It requires numpy, OpenCV and Pillow. It checks RGB4/8/16 smoke envelopes against a15percent reserve and records empty frames and visible-region image changes. The script reproduces the v15 RGB8 framing failure on76of121frames. These measurements do not prove anatomy, real depth, seamless motion or physical projection. Review the complete video at speed and distinguish an authored disappearance from accidental core loss.
