## Current local study: draw correction, lighter surface, faithful recording
The earlier A/B harness suppressed app.render, but production actually draws through app.renderer.render. Consequently those measurements still drew twice per frame. The source harness now intercepts the actual renderer call, updates body and replacement arms, and draws once; this is a local study technique, not a production integration patch. Its clock uses actual bounded elapsed time. Earlier unrecorded-cadence/draw-isolation evidence is superseded.
