# Editable character source

Open Wisp.blend in Blender 4.5+. Select Wisp_Rig and edit the custom properties to change Evil, jaw, lids, brows, smile and tongue together. The Evil slider changes all corresponding mesh shape keys. Compound blink correctives are driven from Evil × side-specific blink. The NLA editor contains Float, Wave, TurnAway and MenacingPace; tracks are muted in the saved source so the rest rig is easy to inspect.

`build_wisp.py` rebuilds the sculpt, weights, UV projection, shape controls, clips, .blend and GLB from the existing painted references. Run it from Blender's background Python mode. The scene packs its two original painted texture sources. Exported GLB has 24 skin joints and matching per-mesh target topology. Runtime spring motion, gaze, material rim/bloom and audio input are implemented in assets/wisp-3d-runtime.js.

The first sculpt needs ongoing art-direction and topology refinement; keep the shared control names and skeleton semantics when replacing geometry. This source is not published to Netlify's browser asset directory.

## Volume-preserving skinning pilot (source-only)
`dual-quaternion-study.js` is an original local GPU normalized dual-quaternion blending experiment, preserving existing material hooks/morphs and normal/tangent rotation. Bone transforms are converted into the mesh bind-local frame first, so common external model scaling is not discarded. It requires rigid relative joint transforms and is NOT enabled in the live runtime.

`verify-dq-gpu.cjs` checks the actual exact GLSL chunks through WebGL2 transform feedback: identity, translation, quarter turn, blended opposite60degree twists preserving radius, quaternion hemisphere agreement, common external nonuniform-scale cancellation and nonidentity bind frame. Chromium and WebKit each7cases pass, maximum position/normal error4.77e-7. An initial opposite±90degree test straddled the mathematically ambiguous180degree relative-rotation midpoint and selected different valid half-turn paths between engines; do not claim deterministic interpolation at that singularity. Actual character action range needs temporal review before adoption.

`review-dq.cjs` captures matched current-GLB baseline/study wave/dance frames across cute/half/evil and front/turned views, no microphone/provider. Five local Chromium cases compiled/rendered without browser/shader errors; maximum bone bind-local orthonormal/determinant deviation3.26e-6. Actual A/B review shows only small differences; the shoulder web and blue UV streaking remain conspicuous. NOT sufficient visual benefit to adopt. Requires complete action/morph/eye-occlusion/temporal/bounds/performance/recovery evaluation if pursued; current CPU bounds still use linear skinning and cannot be assumed correct for a DQ replacement. No geometry, exported GLB, Blender scene, production renderer or voice/control path changed. Prioritize the documented sculpt/topology and intentional painted UV work.
