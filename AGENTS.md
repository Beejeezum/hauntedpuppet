See the reference manifest for approval limits. The laptop is the only audible playback and microphone owner; projector and phone controllers remain silent.

Keep provider credentials on the trusted server: Mac Keychain for the laptop build, Netlify function secrets for the hosted build. Production changes need appropriate regression coverage. Test stop/cancellation, interruptions, farewell-to-idle, resource cleanup and projector silence. Distinguish genuine provider tests from mocks and physical-device tests. Do not describe acoustic mouth estimates as phoneme-accurate.

Prefer small modules and pinned dependencies. Reuse third-party code with retained license/provenance. No renderer migration merely to add a library: demonstrate visual or performance benefit first.

Coordinate file ownership with other agents before changing shared modules. Never restart a key-owning live process just to reload code without planning the private reconnection step.
